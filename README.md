# United Mining Company website

Fresh static HTML/CSS/JS implementation for the UMC Home and About pages.

## Files
- `index.html` — Home
- `about.html` — About
- `styles.css` — shared responsive styling
- `script.js` — mobile navigation, scroll reveal and product rail interaction

The design uses the UMC navy/orange visual language, responsive desktop/tablet/mobile layouts, and a Figma-inspired left-side product hover rail on desktop.
