# United Mining Company website

Static HTML/CSS/JS implementation of the UMC website design.

## Current design source
`WEBSITEPDF/UMC UI (Copy).pdf` uploaded on August 23, 2026 is the sole visual reference for the current Home and About pages.

## Files
- `index.html` — Home page based on PDF page 1
- `about.html` — About page based on the final About frame in PDF page 8
- `styles.css` — shared layout and responsive styling
- `script.js` — mobile navigation only

Previous experimental layouts and product-hover concepts are not part of this version.
